# مساعد محمد

نسخة أولى مجانية من مساعد شخصي عربي RTL، تعمل كـ PWA.

### تعمل حالياً
- محادثة محلية وحفظها في المتصفح.
- تذكيرات محلية.
- إضافة وعرض الملفات محلياً.
- واجهة تكاملات للبريد والرسائل والمكالمات بدون ادعاء صلاحيات غير موجودة.
- PWA وواجهة offline أساسية.
- زر ميكروفون يعتمد على Web Speech API عند توفره.

### الخطوة التالية
ربط مزود ذكاء اصطناعي عبر خادم آمن/متغيرات بيئة، ثم إضافة المصادقة وقاعدة بيانات عند الحاجة.
